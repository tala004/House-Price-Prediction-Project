# House-Price-Prediction-Project
End-to-End House Price Prediction using Machine Learning.

##  Project Overview
This project predicts house prices using the Ames Housing Dataset. It follows a complete data science pipeline including cleaning, EDA, feature engineering, and modeling.

##  Steps Implemented
1. **Data Cleaning:** Handled missing values using Median for numeric and 'None' for categorical data.
2. **Exploratory Data Analysis (EDA):** Identified key price drivers through correlation heatmaps and scatter plots.
3. **Feature Engineering:** - Created a new feature `TotalSF`.
   - Applied **Log Transformation** to normalize the target variable.
   - Encoded categorical variables using Label and One-Hot encoding.
4. **Model:** Built a Linear Regression model with high accuracy.
